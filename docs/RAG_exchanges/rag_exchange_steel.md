# RAG exchange

## Query and model

what steel products are discussed for extending the CBAM?
gemini:gemini-2.5-flash


## Answer

The steel products discussed for extending the CBAM are:

*   (Pre-consumer) scrap of iron and steel, should they be included in the CBAM with attributed embedded emissions (Source: CBAM horizontal extension Final Report _CLEAN_31.10.2025.pdf, page 56).
*   Ferro-alloys:
    *   HS 720221 Ferro-silicon, containing by weight > 55% of silicon (suggested for further consideration) (Source: CBAM horizontal extension Final Report _CLEAN_31.10.2025.pdf, page 53).
    *   HS 720230 Ferro-silico-manganese (suggested for further consideration) (Source: CBAM horizontal extension Final Report _CLEAN_31.10.2025.pdf, page 53).
    *   Other ferro-alloy CN codes that may contain silicon (CN 72022910, 72022990, 72028000, 72029100, 72029930, 72025000), which have not been shortlisted (Source: CBAM horizontal extension Final Report _CLEAN_31.10.2025.pdf, page 53).
    *   All ferro-alloys that may contain silicon or even all CN codes under the HS 4-digit code for ferro-alloys (HS 7202), should the CBAM be extended to ferro-silicon and ferro-silico-manganese (Source: CBAM horizontal extension Final Report _CLEAN_31.10.2025.pdf, page 56).

Evidence:
*   CBAM horizontal extension Final Report _CLEAN_31.10.2025.pdf, page 53
*   CBAM horizontal extension Final Report _CLEAN_31.10.2025.pdf, page 56
